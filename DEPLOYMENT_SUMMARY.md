## 🔧 Configuration Summary

### Web App Settings
```
Root Directory: apps/web
Build Command: npm install && npm run build
Start Command: npm start
Port: 3000 (auto-configured by Railway)
```

### Environment Variables Needed
```
NEXT_PUBLIC_API_URL=https://your-api.up.railway.app
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_... (optional)
```

### API Settings (Already Configured)
```
CORS_ORIGIN=https://your-web-app.up.railway.app (update after deployment)
DATABASE_URL=postgresql://... (auto-set)
REDIS_URL=redis://... (auto-set)
JWT_SECRET=... (set)
```

## 🆘 If You Need Help

### Quick Diagnostics
```bash
# Check API health
curl https://your-api.up.railway.app/health

# Verify web app configuration
cd apps/web
node verify-deployment.js

# Test local build
npm run build
```

### Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| Build fails | Check root directory = `apps/web` |
| CORS errors | Update API `CORS_ORIGIN` |
| No data loads | Verify `NEXT_PUBLIC_API_URL` |
| Env vars not working | Must start with `NEXT_PUBLIC_` |

### Get More Help
- **Troubleshooting Guide:** [WEB_DEPLOYMENT_TROUBLESHOOTING.md](./WEB_DEPLOYMENT_TROUBLESHOOTING.md)
- **Railway Logs:** Dashboard → Service → Deployments → View Logs
- **Browser Console:** F12 → Console tab
