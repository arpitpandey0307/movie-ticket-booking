## 📞 Support Resources

### Documentation
- All guides in this index
- Railway docs: https://docs.railway.app
- Next.js docs: https://nextjs.org/docs

### Troubleshooting
- [WEB_DEPLOYMENT_TROUBLESHOOTING.md](./WEB_DEPLOYMENT_TROUBLESHOOTING.md)
- Railway logs: Dashboard → Service → Deployments
- Browser console: F12 → Console tab

### Testing
- API health: `curl https://your-api.up.railway.app/health`
- Local build: `npm run build` in `apps/web`
- Verify config: `node verify-deployment.js` in `apps/web`
